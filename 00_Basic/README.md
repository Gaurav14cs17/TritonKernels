A ground-up Triton course. Each chapter is **one complete notebook**:
theory → numerical example → applied Triton kernel → forward/backward.

Open [`00_index.ipynb`](00_index.ipynb) first. Every chapter notebook opens with ASCII concept diagrams.

## What one chapter notebook contains

```text
NN_complete.ipynb
├── chapter front matter (thread, objectives, prerequisites, time, difficulty, navigation)
├── chapter map (section, formula, shape/broadcast rule, kernel)
├── concept diagrams
├── Part I — point-wise math cards
│   ├── Connection  (what this builds on)
│   ├── Rule / Formula
│   ├── Example     (LaTeX table or short inline derivation)
│   ├── Where / Triton / Failure
│   └── Bridge      (what comes next)
├── Part II — Method 01: naive CPU reference + asserts
├── Part III — Method 02: Triton micro-kernel + tile map + test
├── Part IV — Method 03: fused/applied kernels + tests
├── capstone kernel
├── forward pass / backward pass derivation
│   ├── full math
│   ├── runnable verification
│   └── silent numerical checks
├── pitfalls table
├── self-check, summary, key takeaways
└── exercises
```

## How to study

1. Read the section theory card.
2. Run the numerical example and check one number by hand.
3. Run the applied example and read the reference assertion.
4. Break one line and explain the failure.
5. Read the forward/backward derivation and re-derive it from a blank page.

Recommended order: **Part 1 → 2 → 3 → 4 → 5 → 6 → 7 → 8**. Then read the
kernel folders `01_vector_addition`–`10_block_scaled_matmul`, which use the same
**Method 01 naive → Method 02 kernel-based → Method 03 fused** ladder.

## Running

```bash
cd 00_Basic
jupyter notebook 00_index.ipynb

# a single chapter
cd part6_reductions/ch16_combining_ops
jupyter notebook 16_complete.ipynb
```

The notebooks import [`ttools.py`](ttools.py) by walking up to `00_Basic`. On a
CPU-only machine the numerical and forward/backward cells run and each GPU test
prints `SKIP ...`.

## Maintaining the book

The chapter notebooks are patched in place by `tools/patch_book.py`, which adds
front matter, navigation, summaries, and checkpoints. The reference apparatus in
`docs/` is generated by `tools/build_docs.py`:

```bash
make book     # rebuild the complete chapter notebooks + index
make smoke    # run every complete notebook under TRITON_INTERPRET=1
```

See [`tools/README.md`](tools/README.md) for the generator layout.

## Relationship to the kernel notebooks

`00_Basic` teaches the primitives. The folders `01_vector_addition` through
`10_block_scaled_matmul` apply them to complete kernels using the same
**Method 01 naive → Method 02 kernel-based → Method 03 fused** structure.
